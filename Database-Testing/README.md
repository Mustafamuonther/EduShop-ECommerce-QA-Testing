# EduShop – Database Testing

This folder documents database testing and verification activities for the EduShop E-Commerce application.

## Tools
- PostgreSQL
- pgAdmin
- SQL

## Testing Scope
- Data integrity and consistency
- Primary key and foreign key constraints
- NOT NULL, UNIQUE, and CHECK constraints
- Database relationships
- CRUD operation verification
- Data persistence after API operations
- SQL queries for validation

## Documentation

Verified SQL queries, database test cases, and execution evidence will be added to this folder.

Note: The testing scope above describes planned documentation areas. Individual tests and results will be included only when supported by actual project evidence. No production data, credentials, or database dumps containing sensitive information should be uploaded.
