# EduShop – Requirements Traceability Matrix

This folder contains the Requirements Traceability Matrix (RTM) for the EduShop E-Commerce QA project.

## Project Requirements

- **Epics:** 9
- **User Stories:** 32
- **Acceptance Criteria:** 79

## Purpose

The traceability matrix connects requirements with their corresponding test cases, execution results, and reported defects.

It helps evaluate test coverage and identify requirements that have not yet been fully tested.

## Traceability Structure

Epic → User Story → Test Case → Execution Status → Linked Bug

## Tools

- Jira
- Microsoft Excel
- Zephyr (where applicable)

## Documentation

The verified traceability matrix will be added after reviewing the actual project records.

Test coverage and execution statistics will only be reported when supported by the exported data.
