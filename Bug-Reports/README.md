# EduShop – Bug Reports

This folder contains defects identified during manual and API testing of the EduShop E-Commerce application.

## Defect Documentation

Bug reports are managed in Jira and may include:

- Bug ID and summary
- Related user story or requirement
- Severity and priority
- Preconditions and steps to reproduce
- Expected result and actual result
- Defect status
- Supporting evidence, where available

## Testing Areas

- User authentication and access control
- Product catalog and shopping cart
- Checkout and order management
- API validation and authorization
- Database-related issues, where verified

## Project Evidence

Verified Jira bug exports and supporting documentation will be added to this folder. Bug counts and statuses will be reported based on the actual exported records.
