
# EduShop E-Commerce — Software QA Testing Portfolio

End-to-end Software Quality Assurance project demonstrating practical experience in Manual Testing, API Testing, Database Testing, Test Management, Defect Tracking, and Requirements Traceability.

## Project Overview

EduShop is an e-commerce application used to practice and document a structured QA process, from requirements analysis and test case design to test execution, defect reporting, and traceability.

The project covers nine functional areas, including authentication, product catalog, category management, shopping cart, checkout, product reviews, wishlist, admin dashboard, and API testing.

## Tools & Technologies

- **Jira:** Requirements management, user stories, and defect tracking
- **Zephyr:** Test case management, test cycles, and execution results
- **Postman:** REST API testing and scripted assertions
- **PostgreSQL / pgAdmin:** Database inspection and testing
- **Docker:** Local application environment
- **Git & GitHub:** Version control and QA documentation
- **Microsoft Excel:** Test documentation, reporting, and traceability

## Testing Scope

### Manual Testing
Functional, negative, validation, access control, and regression-related test scenarios across core e-commerce features.

### API Testing
REST API requests covering authentication and business workflows, with response validation and negative testing.

### Database Testing
Database inspection and verification using PostgreSQL and pgAdmin.

### Defect Management
Documented issues with reproduction steps, expected and actual results, and tracking information in Jira.

### Requirements Traceability
Relationships between user stories, test cases, execution records, and defects, with unverified links identified for review.

## QA Workflow

1. Analyze requirements and acceptance criteria.
2. Organize epics and user stories in Jira.
3. Design and document test cases in Zephyr.
4. Execute functional and API test scenarios.
5. Record actual test results.
6. Report defects and track them in Jira.
7. Review test coverage and requirements traceability.
8. Publish QA documentation on GitHub.
