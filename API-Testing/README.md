# EduShop – API Testing

This folder documents API testing activities for the EduShop E-Commerce application using Postman.

## API Overview

- API Resources: 8
- Documented Endpoints: 32
- Base URL (Local): http://localhost:5000
- Authentication: JWT Bearer Token

## Testing Scope

- HTTP methods: GET, POST, PUT, PATCH, DELETE (where supported)
- Positive and negative API test scenarios
- Request and response validation
- HTTP status code verification
- Authentication and authorization
- Input validation and error handling
- Database verification where applicable

## Tools

- Postman
- Jira
- PostgreSQL / pgAdmin
- Docker

## Documentation

Verified Postman collections, execution results, and API defect reports will be added to this folder as they become available.

Note: Local API endpoints require the EduShop application to be running. No credentials or access tokens should be committed.
