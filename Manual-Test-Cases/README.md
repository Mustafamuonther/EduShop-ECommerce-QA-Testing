# EduShop – Manual Test Cases

This folder contains manual test cases designed to validate the EduShop E-Commerce application against its user stories and acceptance criteria.

## Testing Scope

- User registration and login
- Authentication and access control
- Product catalog and product details
- Product filtering, sorting, and pagination
- Shopping cart and wishlist
- Checkout and order management
- Admin functionality

## Test Case Documentation

Test cases are documented with preconditions, test steps, expected results, actual results, execution status, and related Jira issues where available.

The detailed test case export will be added to this folder.
