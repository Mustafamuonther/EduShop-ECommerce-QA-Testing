# EduShop – Test Execution Results

This folder contains documented test execution results for the EduShop E-Commerce QA project.

## Purpose

Track manual and API test execution outcomes and provide evidence of testing progress and identified defects.

## Execution Status

The following statuses may be used:

- **PASS:** Actual result matches the expected result.
- **FAIL:** Actual result does not match the expected result.
- **BLOCKED:** Test execution cannot proceed due to an issue or dependency.
- **NOT EXECUTED:** Test case has not yet been executed.

## Execution Documentation

Test execution records may include:

- Test Case ID
- Related User Story
- Test Scenario
- Expected Result
- Actual Result
- Execution Status
- Linked Bug ID
- Execution Date

## Tools

- Jira
- Zephyr (where applicable)
- Postman
- Microsoft Excel

## Reports

Verified execution results and summary reports will be added after exporting and reviewing the original project records.

No execution results will be assumed without supporting evidence.
